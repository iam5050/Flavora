# Flavora — Cooking Club Website

A multi-page responsive website for Flavora, a cooking club for students and food lovers. Its tagline is *Cook • Learn • Connect*.

## Pages
- **Home:** welcome section, featured offerings and member testimonials
- **Offerings:** cooking workshops, baking classes and social activities
- **About:** the club's mission and community
- **Instructor profiles:** a page for each instructor
- **Member dashboard:** join and evaluate offerings
- **Manager dashboard:** add offerings and manage instructors

## Built with
- HTML5
- CSS3, with responsive layouts using media queries
